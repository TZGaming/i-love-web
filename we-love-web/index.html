Joes Koppers over Creative Coding

Animaties is belangrijk voor elke website. Ook probeert hij veel originele dingen te bedenken wat niet vaak word gezien op het web. Z'n website ziet er heel netjes en cool uit, heel veel bewegingen en zoiets heb ik zelf nog nooit eerder gezien. Ik heb een vraag gesteld: Hoe zit het met laptops die ouder zijn met slechtere CPUs? Joes: Er word (nog) niet rekening gehouden met oudere apparaten, het werkt er wel op maar waarschijnlijk een stuk trager, er zitten geen fallbacks in. Werktijden.nl

Tom & Tom (haha) zijn allebij ex-FDND studenten Bij werktijden.nl maken ze software voor personeelsplanning, urenregistratie, verlofregistratie en verzuim registratie. Responsive design en accessibility vinden ze het belangrijkst in het algemeen. Ze gebruiken ook GitHub net zoals wij doen met issues, labels en project boards. Ze gebruiken veel frameworks zoals Angular en Tailwind voor het coderen van hun websites.
